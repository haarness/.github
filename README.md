# haarness/.github

Organization-wide defaults for the [Haarness](https://github.com/haarness) repositories:

- [`profile/README.md`](profile/README.md) — the public profile shown at <https://github.com/haarness>.
- [Code of Conduct](CODE_OF_CONDUCT.md), [contributing](CONTRIBUTING.md), [security policy](SECURITY.md)
  and [support](SUPPORT.md) — used by every repository that does not carry its own.
- [Issue templates](ISSUE_TEMPLATE) and the [pull request template](PULL_REQUEST_TEMPLATE.md) — the
  same fallback.

The banners in `profile/assets` are rendered from the brand marks and the Haarness palette; members find
the generator in the private `.github-private` repository.
