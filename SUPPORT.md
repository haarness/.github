# Getting help

- **Documentation**: the user guides at <https://haarness.ai/docs>, and each repository's README and
  `docs/` folder for engineering detail.
- **Diagnose first**: `haarness doctor` checks an install, the bundled tools and your providers.
- **Bugs and feature requests**: open an issue on the repository it concerns, using its templates.
  Search existing issues first.
- **Security problems**: never in a public issue — see [SECURITY.md](SECURITY.md).
- **Haarness Cloud accounts and billing**: admin@haarness.ai.

Issues are handled on a best-effort basis by the maintainers; there is no guaranteed response time for
the open-source projects.
